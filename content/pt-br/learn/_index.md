## Como funciona o Learn

Cada módulo agrupa um conjunto de unidades curtas. Uma unidade explica uma ideia com diagramas, animações passo a passo, gráficos e pequenas demonstrações interativas, e termina com uma verificação de conhecimento. As unidades duram entre oito e quinze minutos.

Seu progresso é armazenado apenas neste navegador. Marque uma unidade como concluída ao final da página, ou passe para a próxima unidade e ela será marcada automaticamente. Nada é enviado a um servidor.

Learn trata de conceitos, não de telas de produto. Quando uma unidade menciona algo que você pode fazer no AIVAX hoje, ela cria um link para a página correspondente na [Documentation](../docs/).
