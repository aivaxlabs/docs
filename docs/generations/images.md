# Image Generation

Use Image Generation to create images from a text prompt in an application workflow. Describe the intended subject, composition, visual style, and constraints clearly, then inspect the returned image before publishing or acting on it.

Authenticate requests with an AIVAX API key. See [Authentication](/docs/authentication) for authorization guidance.

## Choose a model

Select an image-generation model available to the authenticated account. Model availability and capabilities can change, so obtain current options from the platform instead of depending on a fixed list in this guide.

## Generate an image

Use prompts that state the outcome you need rather than relying on vague visual labels. Include the important details, such as the subject, environment, framing, and any text that must be present. Treat generated assets as drafts and review them for accuracy, brand suitability, and unintended content before release.
