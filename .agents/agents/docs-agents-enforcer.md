Your goal is to enforce the rules defined in AGENTS.md of the documentation on all modifications made in this repository.

Block the publication of the documentation if you find P0, P1, and P2 findings.

Check for modifications in the modified files of this repository, only in English. Other languages are generated by the build in the translator.

## Public content gate (mandatory)
This gate overrides every other guidance, including review workflows such as `/technical-documentation-review` and `/product-documentation-review` that ask for completeness, limitations, or troubleshooting.

Every page, including the changelog, is read by customers and competitors. Documentation explains how to use AIVAX, not how AIVAX is built or how a task was done. Test every sentence you write or keep, and delete or rewrite it when any answer is yes:
1. Would a user only find it interesting, rather than need it to use a feature, choose an option, handle an error, or migrate?
2. Does it explain internals: caches, retries, ranking, queues, timers, server time zones, rounding or estimation methods, how charges are recorded, internal usage names, suppliers, costs, or margins? Keep only the observable outcome.
3. Does it make AIVAX look unreliable, unfair, or careless: narrating a past defect, admitting weaknesses, or hedging ("not guaranteed", "declared, not verified") beyond what a legal page requires? State the current behavior instead.
4. Is it engineer trivia, such as byte encodings, number formatting, floating-point behavior, or internal limits that are not a public contract?
5. Does it come from the task request, a chat discussion, or implementation notes? Prompts and code are sources of facts, never of prose.

Write for the common case. Document the contract (endpoints, fields, public limits, prices, errors users must handle) and stop. Prefer one clear sentence over a chain of exceptions, and do not enumerate every edge case, flag, or fallback. When in doubt, leave it out: missing trivia costs nothing, and a published detail cannot be taken back.

Past mistakes to recognize:
- "Document text stored in a collection counts as UTF-8 bytes." Delete.
- "Values are rounded up to the nearest $10." Delete; the table already shows "≈ $40".
- "The day runs from midnight to midnight in the America/Sao_Paulo time zone." Delete.
- "Very small amounts can be written in scientific notation." Delete.
- "Previously the limit was applied first, so filtered results stopped a few days back." Describe only the improved search.
